# h7Landing 📱

**h7Landing** is a simple, modern, and effective landing page designed to direct users to the **Shop** section of an eCommerce website dedicated to selling **iPhones**. The project has a clean, responsive, and attractive interface.

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/Frankie-h7/GiordanoLanding.git
   ```

2. Open `GLanding.html` in a browser or use a live server for development.
3. Customize the content, images, and button URLs to fit your eCommerce.
